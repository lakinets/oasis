Introduction

Creating a custom template begins by creating a folder in the themes directory. The folder name (e.g., test) automatically becomes the template name in the admin settings; you don't need to configure anything else.

Folder Structure

assets/
  • img — images
  • css — styles
  • js — scripts
views/layouts/
  • main.php — main layout
  • main-public.php — public layout

main.php

The main layout responsible for the overall site structure: <html>, <head>, header, footer, CSS/JS inclusion, and rendering the page content.

PHP (Yii2)
<?php
$this->beginPage();
$this->head();
$this->beginBody();
    /* Header, content, footer */
    echo $content;
$this->endBody();
$this->endPage();
  • $this->title — page title
  • $content — content of the specific view file
  • Url::base() and Url::to() — safe URL generation
  • Yii::$app->user->isGuest — conditional authorization logic

main-public.php

Layout for public pages (home, info, downloads) without personal account logic.

PHP (Yii2)
<body class="layout-public" data-route="...">
  • The layout-public class allows applying different styles and JS logic
  • The data-route attribute helps determine the current route on the frontend

CSS Conventions

Auth / Public
  • .auth-form — auth forms container
  • .login-form — login form
  • .form-title — form title
  • .captcha-inline — horizontal captcha layout
Backend
  • .backend-default-index — admin dashboard
  • .login-box — centered login form container
  • .box — general block container
  • .box-primary — primary block with emphasis
Shop / Game Servers
  • .game-servers-index — server list
  • .shop-category — shop category container
  • .pack-items — list of items inside a pack
  • .item-form — item form
Bonuses
  • .bonuses-index — bonus list page
  • .bonuses-form — create/edit form
  • .bonus-codes-index — bonus code list

Grid & Utility

Class Purpose Where used
.row Grid row Forms, lists, blocks with columns
.col-md-3 Left auxiliary column Menu, filters, navigation
.col-md-9 Main content Page working area
.col-lg-3 Fixed left column on large screens Forms (label)
.col-lg-9 Right part of the form (inputs) Bonus, server, ticket forms
.d-flex Flex container Control panels, headers + buttons
.justify-content-between Spreads elements to the edges Header on the left — buttons on the right
.align-items-center Vertical center alignment Toolbars, list rows
.mb-3 Bottom margin (small) Forms, headers, lists
.mb-4 Medium bottom margin Settings sections, forms
.mb-5 Large bottom margin Separation of large sections

Alerts and Buttons

Alerts
Successful action
Error

Red text — .text-danger

Buttons

Use .btn-* to denote actions: primary — main, success — create, danger — delete, warning — status.

Tip: save the file in \protected\l2j and follow class naming conventions — this will make template maintenance and expansion easier in the future.

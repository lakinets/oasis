# Oasis CMS  
Lightweight CMS for Lineage 2 servers and beyond.

## Install
```bash
git clone https://github.com/lakinets/oasis.git
cd oasis
# follow setup instructions in docs/
CMS для игрововых проектов Lineage 2, проект постоен на Yii2, требвование к хосту PHP 8.2+, mod_rewrite, PDO. Устанвока распаковать на хостинг, следовать инструкциям установщика, логин и пароль админстратора будет вамии уставновлен при перввом запуске, документация по виджетам и шаблнам лежит есть в файлах что лежат в корне CMS, админ панель можно найти по адресу ваш-хостbackend информацию об обновления и поддержка на ветке форума https://forummaxi.ru/topic/100146-oasis-релиз Oasis включает несклько готовых шаблонов, и все необходимые модули для управления игровым проектом, админ панель, донаты сервисы игровой магазин включая базу данных предметов по id с описанием которое вставляется автоматически ели админ не вводит свое. Есть защита от перебора подарочных кодов, паролей в виде ограничение на ввод на определенное время. С коробки поддерживаеться только сбока PW soft но есть возможность в на половину автоматическом режиме создать файл конфигурации универсального драйвера под любой проект. Личный кабинет поделен на основные разеды такие как персонаж где видно все персонажи по серверам и их инвентарь, магазин для покупок, пополнение для покупки внутренней валюты, так же есть фома пооддержки пользователей в виде тикетов и прочее как реферальная программа, промокоды для акций от админстрации, история входов, история оплат и другое. Регстрация может быть с подверждением или без подвержения почты, а так же визде капчу можно включить и выключить в админ панели, все страницы создаються динамическими, а настроки проекта осуществляюються а админ панели без вмешательство в код.

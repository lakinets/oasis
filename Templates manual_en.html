Introduction

Creating a custom template in Yii2 starts with a simple folder. Just create a directory in themes/ (e.g., themes/mytheme), and the system will automatically find it. The folder name becomes the template name in the admin settings.

How Theme Overrides Work

Yii2 uses a principle of cascading fallback. This means you can override only those parts of the site you want to change, without copying the entire codebase.

If Yii2 needs to render the page site/index.php, it searches for it in the following order:
  1. Checks the file themes/YOUR_THEME/views/site/index.php. If it exists, it uses it.
  2. If the file is missing, it checks protected/views/site/index.php (base system views).
  3. If it's not there either, it throws an error.

Layouts (main.php & main-public.php)

Layout is the "skeleton" of the site (HTML tags, header, footer). The project uses two main skeletons:

main.php

Main layout. Loads heavy scripts, styles for the authorized zone (Cabinet, Shop, Admin) and outputs the nav-mini navigation menu.

PHP (Yii2)
<?php
$this->beginPage();
$this->head();
$this->beginBody();
    echo $this->render('//layouts/_header'); 
    echo $content; // Page content is inserted here
$this->endBody();
$this->endPage();
main-public.php

Public layout for the homepage and landing pages. It does not contain the cabinet menu and uses lightweight markup.

Payment Systems

Critically Important

The project supports 8 payment gateways. The architecture is divided into two parts: admin management (for the owner) and the code core (for the developer).

1. Where to enable and configure?

Go to Admin -> Payment Systems. You will see cards for all 8 gateways. Each card has a status of OFF or LIVE.

  • Click "Configure" on the desired gateway.
  • Enter the API keys. If testing, enable the "Test Mode" toggle (keys sk_test_...).
  • Click "Check" — the system will make a request to the gateway's API and show if the keys are valid.
  • Click "Enable" so the gateway appears on the deposit page.
2. Webhooks (Critically Important!)
Warning! Without setting up Webhooks, the balance will not be credited. You need to log into the payment system's dashboard and specify the notification URL.

Copy the required URL and paste it into your gateway's control panel:

3. Fee Policy

The system is set up for "Fee Absorption". If a player deposits 100 RUB, they get exactly 100 RUB. The gateway fee is covered by the project (handled in DepositController).

1. Architecture (Lifecycle)
  1. Creation: Player clicks "Pay" -> DepositController::actionCreate creates a DB record with status new.
  2. Redirect: Gateway::buildRedirectUrl() is called, the player is sent to the gateway's site.
  3. Payment: The player pays.
  4. Webhook: The gateway sends a POST request to cabinet/deposit/{provider}-callback.
  5. Validation: Gateway::handleCallback() verifies the signature (HMAC/SHA256).
  6. Credit: DepositController::finalizeAndRespond() delivers items/balance and changes the status to paid.
2. Callback Protection (CSRF)
Important! All *-callback methods in DepositController must have $this->enableCsrfValidation = false; and be accessible to guests ('roles' => ['?']) in AccessControl. Otherwise, the gateway will receive a 403 error.

ASN Filter: Smart Bot Protection

The project implements an advanced protection system against parsers and brute-force attacks. It does not block humans but creates a "trap" for bots.

1. How does it work?
  • Every time a user visits the site, the system determines the ASN (Autonomous System Number) of their IP address.
  • If the IP belongs to a home or mobile ISP (Comcast, AT&T, Vodafone, etc.) — the user gets unrestricted access.
  • If the IP belongs to a data center, hosting, or VPN — the system enables the "Shadow Ban".
2. What is a "Shadow Ban"?
We do not block the bot (it won't know it's caught). Instead, we feed it a fake session and "Zombie Cookies". It thinks it successfully hacked the site, but all its actions occur in an isolated sandbox.
3. Admin Management

Go to Admin -> ASN Whitelist. There you can:

  • Enable/disable the entire filter.
  • Block an entire continent or country.
  • Find a specific provider and disable only them.

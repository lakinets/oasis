Database Configuration File for Oasis

To automatically generate a configuration file for your server, you need to fill in all the fields if they differ from the defaults.
If you don't know the exact name, look for the most similar names in your database. If there are none or you are not sure, search forums or contact the developer of your project.
The resulting file must be placed in the \protected\l2j folder and activated in the admin panel of your website your-site/backend/.

Fill in your fields exactly as they are in your database
